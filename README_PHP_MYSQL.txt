CARA MENJALANKAN DI XAMPP
1. Extract ZIP ini.
2. Copy folder hasil extract ke C:/xampp/htdocs/dapoer_omom
3. Buka XAMPP.
4. Start Apache dan MySQL.
5. Buka http://localhost/phpmyadmin
6. Import file database.sql.
7. Buka http://localhost/dapoer_omom/

CATATAN
- Data menu, user, transaksi, dan detail transaksi disimpan di MySQL.
- Password menggunakan password_hash/password_verify.
- Export Excel menggunakan format .xls yang bisa dibuka Microsoft Excel.
- WhatsApp menggunakan nomor 081386489122.
- Website responsive untuk HP, tablet, dan laptop.
